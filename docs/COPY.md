# Website copy

Every piece of text on the public website, page by page, as it appears today.

How to mark it up: delete a line to remove it, edit a line to change it, write `KEEP` or nothing to leave it. Add a note under any line if you want something different. Then send the file back.

Labels in front of each line say what kind of element it is (H1 = main heading, Link, Button, Field label, Placeholder = grey hint text inside a box). Do not edit the labels.

The eight "Landing page" sections are the Google-only local pages. They are not linked from the site; people reach them from search results.

Not included: the studio admin (only you see it) and the Lightroom plugin.
